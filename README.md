## 🛠️ Key Features

- **Minimalist Swiss-Modern Aesthetic**: Precision typography (Inter & JetBrains Mono), architectural hairline grids, true architectural dark/light theme switching with zero FOUC.
- **Interactive Simulations**:
  - **WallClick Mechanical Node & Demounting Simulator**: Demonstrates non-destructive panel disengagement in under 3 minutes.
  - **Helmholtz Resonant Cavity Tuner**: Dynamically simulates center frequency shift and sound absorption spectrum across 50–220 mm standoffs.
  - **Web Audio Chamber Synthesizer**: Audition live reverberation dampening with real acoustic filtering.
  - **Tile Layout Studio**: Dynamic 500×500 mm grid designer with 5 presets, accent tiles, and DALI-2 LED backlighting controls.
  - **Active Air Biofiltration Airflow Engine**: Real-time canvas particle simulation showing room air draw through root rhizospheres.
  - **4-Layer Leak Defense Simulator**: Interactive breakdown of stainless catchments, moisture sensors, and drain matrices.
  - **Day/Night Lighting Simulator**: Interactive architectural illumination switch between daylight surface and illuminated nighttime glow.
- **CSI MasterFormat Specification Builder**: Generates 3-Part tender specifications (Div 09 22 00, Div 10 22 19, Div 27 11 00) with instant copy & text export.
- **100% Fully Responsive**: Flawlessly optimized across Mobile (375px), Tablet (768px), and Desktop (1440px+).

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)

### 1. Installation
```bash
git clone https://github.com/VeerOP/jometry-architectural-systems.git
cd jometry-architectural-systems
npm install
```

### 2. Run Local Development Server
```bash
npm start
```
Open **[http://localhost:3050](http://localhost:3050)** in your browser.

### 3. Run Automated Responsive & Validation Tests
```bash
node scripts/test-responsive.mjs
```
